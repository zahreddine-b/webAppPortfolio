# Personal Portfolio — BOUKAHEL Zahreddine

## Project Description

This project is a personal portfolio website developed as part of the **WAMD TP-TD 1 assignment** at ENSTA.

The website introduces me, presents my skills and education, showcases my projects, and provides a way to contact me. It features a responsive design, a dark color theme, and interactive elements built with HTML, CSS, and JavaScript.

## About Me

I'm BOUKAHEL Zahreddine, a Computer Science student specializing in Cybersecurity at ENSTA. I'm interested in technology, sports, and discovering new skills. I'm continuously working to improve my technical knowledge and develop useful projects.

## Technologies Used

- **HTML5** — Page structure and semantic elements.
- **CSS3** — Styling, responsive layouts, animations, and visual design.
- **JavaScript** — Interactive elements, mobile navigation, and language switching.

## Features

- **Responsive design:** Adapts to desktop, tablet, and smartphone screens.
- **Dark theme:** Uses dark backgrounds with green and blue accents.
- **Navigation menu:** Provides access to the main sections of the portfolio.
- **About section:** Introduces my background and interests.
- **Skills section:** Presents my programming languages and tools.
- **Projects section:** Showcases my project, MEDapp.
- **English/French language switch:** Allows visitors to switch the website language.
- **Contact section:** Provides contact information and a contact form.
- **Subtle animations:** Adds visual feedback while keeping the interface simple.

## ▶️ How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code or another code editor.
3. Make sure the CSS and JavaScript files are in their correct folders.
4. Open `index.html` in a web browser.

For convenient development, you can also use the **Live Server** extension in Visual Studio Code.

## 🧪 Testing

The website should be tested in a modern browser such as Google Chrome or Mozilla Firefox.

Testing checklist:

- [ ] Navigation links lead to the correct sections.
- [ ] The mobile menu opens and closes correctly.
- [ ] The English/French language switch works.
- [ ] The layout adapts to different screen sizes.
- [ ] The contact form works after its configuration and verification.
- [ ] No major errors appear in the browser console.
